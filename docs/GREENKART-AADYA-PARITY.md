## Adaptation Principles

1. **Zero Brand Pollution**: No GreenKart asset, green color scheme, or plant/gardening text will enter Aadya. All content stays focused on home decor, handcrafted art, sacred objects, and monographs.
2. **Design System Protection**: Every new UI component must consume Aadya's CSS variables and design tokens (`--color-terracotta`, `--color-sage`, `--color-charcoal`, `--font-serif`, etc.).
3. **Additive Schema Updates**: Database modifications use non-destructive Prisma schema additions to preserve existing orders, products, and user accounts.
4. **End-to-End Public Verification**: Every admin configuration option must be connected to a public storefront consumer component.
